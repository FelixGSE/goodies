# goodies

A mix of computational geometry, algebra utilities and higher-level stuff
like brushes, flow fields, grids and Chaikin curves, for use in
[Processing](https://processing.org/). The part I care about most and that
other libraries don't do: shapes in N dimensions, rotated and projected down
until they fit on a canvas.

I started this a few years ago as a hobby project. I kept building the same
things in my sketches, so I pulled them out into a library. It was also my
way of exploring computational geometry and algorithms, and later Kotlin.
Code quality was not the focus. It shows (hobby project)

Now I restarted it. Fresh history: the initial commit is the embarrassing
state, minus the even more embarrassing history. The repo it came from had
years of commits called "backup", so nothing of value was lost.
